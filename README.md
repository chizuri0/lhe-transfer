# LHe Transfer Helper

A small phone-friendly web tool for logging liquid-helium transfers: enter Dewar (cm→L via lookup table), Plant (L direct or cm→L formula), and gas (psi→L); it computes efficiency and total He, saves records locally, and exports CSV.

Live: https://chizuri0.github.io/lhe-transfer/

All data stays in your browser (localStorage) — nothing is sent anywhere. Export CSV for backup.
